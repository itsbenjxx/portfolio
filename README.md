# Portfolio Personnel 

> Application web full-stack développée avec Angular 22 et Node.js.

[Lien vers la version en ligne](https://benjamin-fourmont.fr/) 

---

## 📌 Présentation

Ce projet est mon portfolio professionnel. Il présente mes compétences, mes projets phares et permet une prise de contact. L'objectif de ce dépôt est de mettre en avant la structure de mon code, l'architecture choisie et les bonnes pratiques de développement web moderne.

## 🛠 Tech Stack

### Frontend
* **Framework :** Angular 22 (Standalone Components, Signals)
* **Style :** [SASS / Angular Material]
* **State Management :** Signals / RxJS

### Backend
* **Runtime :** Node.js
* **Framework :** NestJS
* **Base de données :** [PostgreSQL] 

---

## 🚀 Fonctionnalités Clés

* **Architecture moderne :** Utilisation des Signals d'Angular 22 pour une gestion d'état réactive et performante.
* **API REST Node.js :** Gestion du formulaire de contact, envoi d'emails et récupération dynamique des projets.
* **Design Responsive :** Adapté à tous les écrans (Mobile, Tablette, Desktop).
* **Performance & SEO :** Optimisation des assets, lazy loading des routes et rendu rapide.
